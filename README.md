# HR Attendance Analytics Project

## Project Overview

This project analyzes employee attendance, overtime, paid leave, absenteeism, and department performance using Python, SQL, and Excel.

---

## Business Problem

HR departments need a reliable way to monitor employee attendance, overtime, leave utilization, and absenteeism. Manual tracking is time-consuming and prone to errors.

---

## Project Objectives

- Clean raw attendance data
- Generate daily attendance records
- Calculate overtime hours
- Track paid leave
- Identify true absenteeism
- Create HR dashboards
- Generate business insights
