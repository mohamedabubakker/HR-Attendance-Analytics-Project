# Corporate Workforce & HR Intelligence System

## Project Overview

Developed an end-to-end HR Analytics solution to transform raw workforce data into actionable business insights. The project integrates employee attendance, shift schedules, leave records, payroll, and department information to monitor workforce performance, overtime utilization, absenteeism, and operational efficiency. The solution demonstrates a complete analytics workflow, including data cleaning, transformation, SQL analysis, KPI development, and interactive dashboard reporting.

---

## Business Problem

Organizations often manage HR data across multiple systems, making it difficult to monitor attendance, overtime, leave utilization, and departmental productivity. This project consolidates workforce data into a centralized analytics solution, enabling HR teams to make faster, data-driven decisions.

---

## Project Objectives

* Build a centralized HR analytics data model.
* Clean and transform raw attendance and employee data.
* Calculate daily working hours and overtime.
* Identify paid leave and true absenteeism.
* Analyze attendance trends and department performance.
* Develop KPI reports and interactive dashboards for HR management.
